# IP-SAKTI Frontend

This project contains the frontend structure for the IP-SAKTI application.

## Getting started

```bash
npm install
npm run dev
```

## Project structure

- `src/components` contains reusable UI pieces grouped by feature.
- `src/pages` contains route-level screens.
- `src/services` contains API and domain client helpers.
- `src/context` stores app-level state.
- `src/hooks` contains custom hooks.
- `src/utils` stores constants and helper functions.
